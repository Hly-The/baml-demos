TypeScript مع طرق `snake_case`، وحقول `name: type`، وأنواع تعداد، وواجهات، وأنواع عامة، وإغلاقات، وتسلسل اختياري، وسلاسل علامات اقتباس مع استيفاء `${...}`، و`.to_string()` على أي قيمة، ومكتبة قياسية حقيقية. ولغة برمجة خاصة بالمجال (DSL) تصريحية لاستدعاءات LLM (`function … { client: prompt: }`, `test`) تُحوّل إلى صيغة مُبسّطة، بحيث يكون الناتج المُهيكل للنموذج مجرد قيمة إرجاع مُحددة النوع. **واجهة سطر الأوامر (CLI) هي التوثيق. اكتشفها عبر `baml describe`:** ```bash brew install baml # ملف تنفيذي لواجهة سطر الأوامر: `baml` baml init # مشروع جديد (baml.toml + baml_src/) baml help <command> # خيارات وأمثلة واجهة سطر الأوامر baml describe baml.json # مرجع لأي وحدة/نوع/طريقة/توقيع/كلمة مفتاحية baml describe Array --budget 120 # (Array, String, Map, assert, match, patterns, spawn, python, ...) # ينتهي بـ "عدد N من الأسطر الإضافية"؟ أعد التشغيل باستخدام `--budget <N>` baml check # التحقق من تجميع المشروع baml run -e 'expr' # تقييم تعبير؛ للحصول على ملاحظات سريعة وفحص بناء الجملة، استخدم الأمر `baml test --list && baml test`. ثم شغّل كل كتلة اختبار/مجموعة اختبار باستخدام الأمر `baml fmt baml_src/main.baml`. بعد ذلك، قم بتوحيد تنسيق المشروع باستخدام الأمر `baml describe <name>`. يطبع هذا الأمر **نص المصدر الكامل** لوظائف المكتبة القياسية، وهي أسرع طريقة للتحقق من السلوك، والطريقة الوحيدة للوظائف المضمنة مثل `assert` (لا حاجة لملف على القرص). لا تحتاج الدوال النقية إلى اختبار/عميل، يمكنك التحقق منها باستخدام الأمر `baml run -e 'add(2, 3)'`. لا تصف واجهات برمجة التطبيقات الموضحة أدناه إلا إذا واجهت بعض الأخطاء. يمكنك البدء بناءً على الأمثلة واستخدامها إذا واجهت المزيد من الأخطاء أو كنت تريد تفاصيل المكتبة القياسية الفعلية. يتصرف BAML في الغالب مثل JavaScript/TypeScript، مع بناء جملة مشابه جدًا، ولكنه أكثر دقة وصرامة. ## أفضل الممارسات والمعلومات - **دالة LLM = قيمة مُعادة مُحددة النوع.** نوع القيمة المُعادة هو المخطط الذي يجب أن يُنتجه النموذج (`class`, `enum`, literal union, `string[]`, `T?`). المُخرجات المُهيكلة هي ببساطة قيمة مُحددة النوع - قم بتمريرها إلى الكود العادي. - **المطالبات عبارة عن سلاسل نصية بين علامتي اقتباس معكوسة مع استيفاء `${...}`.** اكتب `prompt:` ``… ${arg} …``، و**قم دائمًا بإضافة `${ctx.output_format}`** للحصول على قيمة مُعادة مُهيكلة. استخدم `\`` / `\${`; للتداخل مع علامات اقتباس معكوسة إضافية. - **العملاء عبارة عن قيم، وليست كتل تهيئة.** `client Fast = openai.ResponsesClient.new(model = "…", api_key = env.OPENAI_API_KEY);` — تمت إزالة كتلة `client<llm> Name { provider: …, options: {…} }` القديمة. أي شيء يُنفذ واجهة `ai.Client` يعمل (`openai.ResponsesClient`، `openai.ChatClient`،`anthropic.AnthropicClient`، ... (تختلف معلمات المُنشئ باختلاف المُزوّد). يقبل كل من `api_key` و`base_url` قيمة `ai.Credential`: سلسلة نصية حرفية، أو `null` للقيمة الافتراضية للمُزوّد، أو مرجع `env.NAME` مرتبط لاحقًا ويتم حله عند وقت الطلب. عزز الموثوقية عن طريق **التغليف**: يحتوي كل من `ai.clients.Retry.new(inner = c, max_attempts = 3)` و`ai.clients.RoundRobin.new(members = [...])` على `.new`، بينما لا يحتوي `ai.clients.Fallback { members: [...] }` على ذلك - قم بإنشائه كقيمة حرفية للفئة. ثم استخدم `client: Fast` في الدالة، أو الاختصار `client: "openai/gpt-4o-mini"`. `baml describe openai` / `baml describe ai.Credential` / `baml describe ai.clients`. - **تشكيل المخطط باستخدام سمات الحقول.** `@description("…")` يضيف تلميح `///` يراه النموذج في `${ctx.output_format}`؛ `@alias("name")` يعيد تسمية مفتاح JSON المُخرَج. السلسلة: `tags: string[] @alias("labels") @description("…")`. - **اختبار الكود فقط، وليس النموذج.** اختبر وحدة التنسيق/المعالجة اللاحقة على بيانات حرفية باستخدام `assert.`*. استدعاء دالة LLM في `test` يُنشئ طلبًا حقيقيًا - وليس اختبارًا غير متصل بالإنترنت. (توجد الدوال `f$parse`/`f$render_prompt`/`f$build_request` لأغراض تصحيح الأخطاء.) - **بناء السلاسل النصية باستخدام الاستيفاء، وليس الإكراه.** تُحوّل الدالة ``score=${n}`` أي قيمة إلى سلسلة نصية (ضمنياً باستخدام `.to_string()`)؛ استدعِ `.to_string()` للسلسلة النصية فقط. تتطلب الدالة `+` أن يكون كلا طرفيها سلسلتين نصيتين (لن يتم تجميع `"n=" + 5`). - **`catch` لبعض الأخطاء، و`catch_all` لجميعها.** تعالج الدالة `expr catch (e) { baml.errors.ParseError => fallback }` خطأً *محددًا*؛ بينما الدالة `expr catch_all (e) { _ => fallback }` شاملة *لنقطة بداية/بداية سير العمل. تنتشر الأخطاء ضمنيًا؛ ولا يحتاج المستدعون إلى إعادة تعريفها. **أطلق استثناءً** باستخدام `throw baml.errors.InvalidArgument { message: "…" }` (أنواع الأخطاء هي فئات `baml.errors.*` المضمنة — `InvalidArgument`/`ParseError`/`Io`/`Timeout`/…؛ `baml describe baml.errors`)؛ علّق على توقيع قابل للخطأ باستخدام `-> T throws ErrType`. يُفضّل استخدام **اتحاد** النتائج المُحددة النوع (`type R = Ok | Err`) بدلاً من الاستثناء للتحكم في تدفق البرنامج العادي. - **الواجهات = سلوك مشترك + إرسال ديناميكي.** `interface I { function m(self) -> T }` (قد تحتوي الطرق على أجسام افتراضية)؛ تُفعّل الفئة ذلك عبر `implements I { … }`؛ يتم إرسال قيمة مُحددة النوع `I` (أو `I[]`) إلى المُنفّذ في وقت التشغيل. يمكن للواجهات أيضًا تعريف أنواع مرتبطة وحدود عامة. `baml describe interfaces`. - **مطابقة الأنماط.** `match (v) { … }` على القيم/الأنواع؛ الأذرع هي `pattern => expr` — القيم الحرفية، `let x: T` (ربط + تضييق)، تفكيك الفئة `T { f: let y }`، أنماط `or` `A | B`، الحراس `… if cond`، `_`؛ يجب أن تكون شاملة. أيضًا `v is T` → bool (تضييق) و`if let x: T = v { … } else { … }`. `baml describe patterns`. - **التزامن = الخيوط الخضراء.** `spawn { … }` تُرجع `Future`؛ `await` تجمعها. اجمع العديد منها مع `baml.future.all` / `all_complete` / `race` / `any` (JS `Promise.*`). قم بتهيئة عملية إنشاء فرعية باستخدام عبارة `with`: `spawn with baml.spawn.options(group = g, cancel = tok, detach = true) { … }` — `baml.spawn.TaskGroup.new(n)` يحد من التزامن (يتم وضع عمليات الإنشاء الفرعية الزائدة في قائمة الانتظار FIFO)، ويقوم `baml.spawn.CancelToken` بالإلغاء بشكل تعاوني. `baml describe spawn` / `baml describe baml.future`. - **أمان الموارد — `defer`، `cleanup`، `catch (e, ctx)`.** `defer { … }` يُشغّل كتلة برمجية عند الخروج من النطاق، LIFO، على *كل* مسار (إرجاع / طرح / تجاوز) — مثل لغة Go. دالة الفئة المسماة `function cleanup(self) -> void` هي دالة **نهائية**: تُنفذ مرة واحدة على الأكثر لكل نسخة، سواءً استدعيتها أو `defer` أو استعادها جامع البيانات المهملة. يربط `catch (e, ctx)` سياق خطأ **`ErrorContext`** بالخطأ - حيث يُضاف إليه خطأ تم طرحه أثناء معالجة سلسلة أخرى، لذا فإن `ctx.root_cause()` / `ctx.cause` يعودان إلى الخطأ الأصلي، و`ctx.to_string()` يُنشئ السلسلة بأكملها (على غرار `__context__` في بايثون). تستمر حلقة `while let PATTERN = expr { … }` حتى يفشل النمط (مثل تفريغ دالة `pop()` التي تُرجع `T?`). - **استدعاء BAML من بايثون/تايب سكريبت.** قم بتعريف `[generator.<name>]` في `baml.toml`، ثم شغّل `baml generate`، ثم استورد `baml_sdk` المُعرّف. التثبيت والاستخدام: `baml describe python` / `baml describe typescript` / `baml describe baml_sdk`. - **وصول آمن عبر الفهرسة.** يحدث خطأ في الفهرسة عند فقدان فهرس/مفتاح؛ استخدم `.at(i)`/`.get(k)` (→ `T?`)، أو استخدم `?.` للوصول المباشر، أو استخدم `??` كقيمة افتراضية (بين قوسين: `(m.get(k) ?? 0) + 1`). - **تُكتب دوال المكتبة القياسية بنمط snake_case، وتُستدعى على قيمة.** بعضها يُعيد قيمة جديدة، وبعضها يُجري تعديلات مباشرة على القيمة، وقليل منها يُجري كلا الأمرين (مثل `sort_by_key` التي تُرتّب القيمة المُستقبِلة *وتُعيدها*) — لقراءة التوثيق، استخدم `baml describe <word/type/identifier/keyword/etc>`. - **حقول الفئة `name: type`؛ يُنشئ `Type { field: val }`.** تأخذ الدوال كائن `self` فقط؛ أما الدوال المُنشئة فهي دوال حرة. **الحقول قابلة للتعديل** (مثل TypeScript): `obj.field = v` و`obj.field += n` تعملان، ويمكن لدالة `self` إجراء تعديلات مباشرة على القيمة — تُعيد دالة التأثير الجانبي `void`. **الأصناف هي أنواع مرجعية**: تُعيد الدوال `find` و`at(i)` و`subscript` اسمًا بديلًا *فعليًا*، وليس نسخة، لذا فإن تعديل النتيجة يُعدّل ذلك العنصر داخل المصفوفة (`xs.find(p)?.n += 1` يُحدّث `xs`)، ويمكن تعديل الصنف المُمرّر إلى دالة بواسطة الدالة المُستدعاة. يدعم النظام نشر تحديث البنية: `User { ...u, tier: Tier.Free }`. **الأصناف الفارغة مسموحة** (`class Marker {}`) - مفيدة كمتغيرات اتحاد. **التعدادات هي متغيرات بسيطة - لا توجد دوال، ولا بيانات مرتبطة** (لن يتم تجميع `EAfoo()`)؛ ضع السلوك في دوال حرة تُطابق `match`. `enum E { A, B }`، الوصول إلى `EA`. - **الكتل هي تعابير** - التعبير الأخير هو القيمة (بدون فاصلة منقوطة `;`)؛ `return x;` للخروج المبكر. الدالة ذات التأثير الجانبي فقط تُرجع `void`؛ وقيمة الوحدة في كتلتها هي `null`. تُكرر حلقة `for (let x in xs)` القيم؛ وتُكرر حلقة `while (cond) { … }`. تستنتج الدوال المغلقة `(x) -> { ... }` المعامل/القيمة المُرجعة من السياق (يُشار إلى `(x: T) -> R` فقط عند وجود غموض؛ و`->` مطلوب). تُرجع الدالتان `.map` و`.filter` المصفوفات مباشرةً (لا حاجة إلى `.collect()`). تحتاج الخريطة الفارغة إلى نوع: `let m: map<string, int> = {};`. - **لا يوجد شرط ثلاثي — `if/else` هو التعبير.** لا يوجد `cond ? a : b`؛ `if (cond) { a } else { b }` هو تعبير يُرجع قيمة، لذا قم بتعيينها مباشرةً: `let label = if (x > 3) { "big" } else { "small" };`. كل فرع عبارة عن كتلة يكون تعبيرها الأخير هو قيمتها (بدون `return`). قم بربطه مع `else if`، وقم بإقرانه مع `if let PATTERN = expr { … } else { … }` لربط وتضييق نطاق الشرط. - **تستخدم الشروط خاصية الصدق.** تقبل عبارات `if` و`while` وحراس المطابقة و`&&` و`||` و`!` أي قيمة. القيم الخاطئة هي `false` و`null` والصفر العددي والسلاسل النصية الفارغة والمصفوفات/الخرائط الفارغة والبايتات الفارغة؛ كل شيء آخر صحيح. لا تزال `&&` و`||` تُرجعان `bool`، وليس قيمة مُعامل. يُضيّق الخيار الصحيح نطاق الفرع المُختار. - **تحتوي المصفوفات على مجموعة طرق مشابهة لـ JavaScript** — `map`/`filter`/`filter_map`/`reduce`/`find`/`some`/`every`/`flat_map`/`slice`/`concat`/`join`/`includes`/length()، بالإضافة إلى `push`/`pop`/`shift`/`unshift`/`sort_by`/`sort_by_key` المُدمجة. تقبل معظمها دوالًا مغلقة قد تُطلق استثناءات. يُقدّم الأمر `baml describe Array` مزيدًا من المعلومات. - روابط let المحلية قابلة لإعادة التعيين (x = x + 1) — لا توجد كلمة مفتاحية mut (إنها let في TypeScript، وليست في Rust)؛ ولا توجد const أيضًا. - **الوسائط: القيم الافتراضية مع `=`، واستدعاءات الكلمات المفتاحية مع `=` (لا تستخدم `:` أبدًا).** عرّف قيمة افتراضية في التوقيع: `function f(a: int, b: int = 10)`؛ استدعِ `f(1)` أو `f(1, b = 2)`. **يجب تمرير المعامل الافتراضي بالاسم** — `f(1, 2)` خطأ (يجب تمرير المعامل الافتراضي 'b' بالاسم). يمكن تمرير أي معامل (حتى المطلوب) بالاسم (`f(a = 1, b = 2)`)، ويمكنك تخطي قيمة افتراضية متوسطة لتعيين قيمة لاحقة (`f(1, c = 9)`). صيغة الكلمات المفتاحية هي `name = value`؛ لن يتم تحليل `name: value` (`:` مخصصة للأنواع/الحقول). **لا يجعل `T?` الوسيط اختياريًا** — على عكس `b?: T` في TypeScript، لا يزال الوسيط `b: T?` *مطلوبًا* (يجب تمرير `null`، وإلا سيتم عرض رسالة "تم توقع N وسيطًا، وتم الحصول على ..."). أضف `= null` لجعله قابلاً للحذف. تتبع الدوال المضمنة هذا النمط: `baml.http.fetch(url, timeout = baml.time.Duration.from_seconds(10))`. - **أين يختلف عن TypeScript (المزالق الصامتة):** العمليات الحسابية *مُعتمدة على النوع*، وليست على نمط TypeScript. `int / int` هو **قسمة عددية صحيحة مُقتطعة** (`285 / 100 == 2`، وليس `2.85`) و`%` هو الباقي (`285 % 100 == 85`). يتم تجميع هذا الكود بنجاح، ولكنه يُعطي قيمة خاطئة دون أن يلاحظها أحد، لذا فهو الخطأ الأكبر. عند دمج عدد عشري، نحصل على قسمة عدد عشري (285 / 100.0 == 2.85، 285.0 / 100 == 2.85)؛ أي عملية مختلطة من نوع `int`/`float` تُحوّل إلى `float` (5 + 2.0 == 7.0). **لا يوجد `.to_float()`** — لتحويل عدد صحيح باستخدام `n * 1.0` (أو القسمة على عدد عشري). **لا** يتم تحويل نتيجة `int` تلقائيًا إلى `float` عند الإسناد (`let x: float = 285 / 100` خطأ في التجميع). `+` **للأعداد فقط**: دمج السلاسل النصية يتطلب أن يكون كلا الطرفين من نوع `string` (`"n=" + 5` لن يتم تجميعه — استخدم `${...}` للدمج). المقارنات (`==`, `<`, …, `==` الهيكلية) و`&&`/`||`/`!` تُشبه تلك الموجودة في TypeScript. - **الاختبارات:** اختبار واحد فقط `test "name" { ... }` (بدون غلاف)؛ `testset` مجموعات فقط. التأكيدات (6 فقط): `assert.equal`/`approx_equal`/`is_true`/`is_type`/`not_null`/`contains`. يقارن `assert.equal` **هيكليًا** (بشكل عميق، عبر الفئات/المصفوفات/الخرائط) - // `catch (e, ctx)` binds the error AND its ErrorContext; throwing while handling
// chains the new error onto the one being handled, so root_cause() walks to the origin.
function root_cause_demo() -> string {
    fail_a() catch (e, ctx) {
        _ => fail_b() catch (e2, ctx2) {
            _ => match (ctx2.root_cause().error) {      // ctx.to_string() renders the full chain
                let io: baml.errors.Io => io.message,   // "disk full" - the original cause
                _ => "unknown",
            }
        }
    }
}

// spawn returns a Future; baml.future.all/all_complete/race/any combine many (JS Promise.*).
function concurrent_squares(xs: int[]) -> int {
    let futures = xs.map((x) -> { spawn { x * x } });   // all run concurrently
    let squares = await baml.future.all(futures);
    squares.reduce((a, b) -> { a + b }, 0)
}

// Configure a spawn with `with baml.spawn.options(...)`: a TaskGroup caps concurrency
// (excess spawns queue), a CancelToken cancels cooperatively, detach reparents the task.
function rate_limited() -> int {
    let g = baml.spawn.TaskGroup.new(2);
    let a = spawn with baml.spawn.options(group = g) { 1 };
    let b = spawn with baml.spawn.options(group = g) { 2 };
    (await a) + (await b)
}

// while-let drains an optional-returning source; the loop exits when the pattern fails.
function drain(stack: string[]) -> string {
    let out = "";
    while let item: string = stack.pop() { out = out + item; }
    out
}
